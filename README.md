# Repo Map

Открой папку с проектом и посмотри на её устройство со стороны: файлы, классы и функции превращаются в трёхмерную карту, а импорты показывают, как части кода связаны друг с другом.

**[Скачать для Windows](https://github.com/whydoyouseegit/repomap/releases/latest)** · [Руководство](docs/USER_GUIDE.md) · [Запуск из исходников](docs/DEVELOPMENT.md) · [Сообщить об ошибке](https://github.com/whydoyouseegit/repomap/issues)

## Установка за минуту

1. Открой [последний релиз](https://github.com/whydoyouseegit/repomap/releases/latest).
2. Скачай **`Repo-Map-Setup-0.1.3-x64.exe`**.
3. Запусти файл, выбери язык и папку установки. Мастер создаст ярлыки.
4. Открой **Repo Map** и нажми **Открыть папку**.

Установщик — один файл со всем необходимым. Node.js и npm для готовой программы не нужны. Поддерживаются Windows 10/11, 64 бита. Git нужен только для открытия проектов по Git-ссылке.

## Что можно делать

| Возможность | Как это работает |
| --- | --- |
| Открыть свой проект | Выбери любую локальную папку через системный диалог |
| Подключить репозиторий | Вставь HTTPS- или SSH-ссылку: программа клонирует проект локально |
| Исследовать карту | Вращай, приближай, переключай сферу и скопления по папкам |
| Найти нужное место | Ищи по имени файла, класса или функции |
| Разобраться в связях | Выбери узел и посмотри состав, импорты и фрагмент кода |
| Сохранить структуру | Выгрузи карту в JSON без исходного кода |

Для локальной папки интернет не нужен. Анализ выполняется на компьютере. Repo Map читает файлы, но не запускает и не изменяет код проекта.

## Первые шаги

Сразу после запуска открыт демонстрационный проект с меткой **DEMO**. На нём можно попробовать управление. Чтобы перейти к своему коду, нажми **Открыть папку**. После изменений в проекте нажми **Обновить** — карта сама пока не перечитывается.

| Действие | Управление |
| --- | --- |
| Повернуть карту | Зажми левую кнопку мыши и двигай курсор |
| Сдвинуть карту | Зажми правую кнопку мыши |
| Приблизить / отдалить | Колесо мыши или кнопки `+` / `−` |
| Посмотреть узел | Нажми на точку или строку в дереве |
| Найти файл или символ | Нажми `/` и введи имя |
| Поставить вращение на паузу | Пробел |
| Вернуть исходный ракурс | `R` |

Подробности, примеры и ответы на частые вопросы — в [руководстве пользователя](docs/USER_GUIDE.md).

| --- | --- |
| `Repo-Map-Setup-0.1.3-x64.exe` | Установить программу на Windows |

Саму программу также можно собрать для Linux и macOS. Инструкция — в [документации для разработки](docs/DEVELOPMENT.md).

## Что важно знать

- **JS / TS / JSX / TSX** разбираются через TypeScript AST. Для Python, C/C++, Java, C#, Rust и Go используется упрощённое выделение символов.
- Карта показывает структуру и импорты. Полного графа вызовов в этой версии нет.
- Есть лимит 6 000 файлов. `node_modules`, `.git`, результаты сборки и ряд других служебных папок пропускаются.
- Установщик пока без цифровой подписи. Windows SmartScreen может показывать предупреждение о неизвестном издателе. [Подробнее о подписи](docs/WINDOWS_SIGNING.md).

Все ограничения анализа собраны [здесь](docs/ANALYSIS.md).

## Для разработчиков

```sh
git clone https://github.com/whydoyouseegit/repomap.git
cd repomap
npm ci
npm start
```

Нужен Node.js **22.12 или новее**. [Сборка, проверки и структура проекта](docs/DEVELOPMENT.md).
