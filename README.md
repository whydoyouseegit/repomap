> [!NOTE]
> Проект находится в ранней разработке. Для JavaScript и TypeScript используется синтаксический разбор; для остальных поддерживаемых языков — упрощённый анализ. Карта показывает структуру и импорты, а не полный граф вызовов.

> [!IMPORTANT]
> Windows-установщик пока не имеет цифровой подписи издателя, поэтому SmartScreen может показывать предупреждение. Оно само по себе не подтверждает ни безопасность, ни вредоносность файла. Исходники открыты: программу можно [собрать самостоятельно](docs/DEVELOPMENT.md). Подробнее — в [документации о подписи](docs/WINDOWS_SIGNING.md).

## ✨ Возможности

- **Вселенная проекта.** Файлы, папки, классы и функции на объёмной карте с вращением и приближением.
- **Два вида карты.** Общая сфера или отдельные скопления по папкам.
- **Связи между файлами.** Просмотр импортов выбранного узла или всех найденных импортов сразу.
- **Локальные папки и Git.** Открытие проекта с компьютера или клонирование по HTTPS- и SSH-ссылке.
- **Поиск и фильтры.** Поиск по имени файла или символа, фильтрация по типу узлов.
- **Инспектор кода.** Путь, состав узла, найденные связи и фрагмент исходника с номерами строк.
- **Экспорт в JSON.** Сохранение структуры и связей без включения исходного кода.
- **Работа офлайн.** Анализ локальных папок на твоём компьютере, без сервера анализа.

Repo Map читает файлы проекта, но не запускает и не изменяет его код. Интернет нужен для клонирования удалённого репозитория; после загрузки с ним можно работать локально.

## 🚀 Установка

Готовая версия для **Windows 10/11 x64**:

1. Открой [последний релиз](https://github.com/whydoyouseegit/repomap/releases/latest).
2. Скачай файл `Repo-Map-Setup-<версия>-x64.exe`.
3. Запусти установщик, выбери язык и папку установки.
4. Открой **Repo Map** через созданный ярлык.

Установщик содержит всё необходимое. **Node.js и npm не нужны.** Git понадобится только для открытия проекта по Git-ссылке.

| Файл в релизе | Что внутри |
| --- | --- |
| `Repo-Map-Setup-<версия>-x64.exe` | Установщик Windows |
| `Repo-Map-Source-<версия>.zip` | Исходники, документация и пример проекта |
| `Repo-Map-Release-Pack-<версия>.zip` | Установщик, исходники и короткая инструкция |
| `SHA256SUMS.txt` | Контрольные суммы файлов |

Для Linux и macOS доступны [инструкции по сборке](docs/DEVELOPMENT.md#linux-и-macos).

## 🪐 Первые шаги

После запуска откроется демонстрационный проект с меткой **DEMO** — на нём можно попробовать управление.

Нажми **Открыть папку** и выбери корень своего проекта. Дождись анализа, затем нажми на узел: справа появятся сведения о нём, связи и вкладка с кодом. Для удалённого проекта используй кнопку **Git-ссылка**; Git должен быть установлен на компьютере.

| Действие | Управление |
| --- | --- |
| Вращение карты | Левая кнопка мыши + движение |
| Сдвиг карты | Правая кнопка мыши или Shift + левая |
| Приближение и отдаление | Колесо мыши, `+` / `−` |
| Выбор узла | Один клик |
| Фокус на узле | Двойной клик или выбор в дереве |
| Поиск | `/` |
| Пауза вращения | Пробел |
| Исходный ракурс | `R` |
| Снять выделение | `Esc` |

После изменения исходников нажми **Обновить** — автоматического отслеживания файлов пока нет.

## 💻 Запуск из исходников

Понадобятся **Node.js 22.12 или новее**, npm и Git.

```sh
# Клонировать репозиторий
git clone https://github.com/whydoyouseegit/repomap.git

# Перейти в папку проекта
cd repomap

# Установить зависимости
npm ci

# Запустить приложение
npm start
```

Для первой установки зависимостей нужен интернет. После установки локальные проекты можно анализировать офлайн.

### Проверки и сборка

```sh
# Запустить тесты анализатора
npm test

# Собрать Windows-установщик на Windows
npm run build:win

# Собрать AppImage на Linux
npm run build:linux

# Собрать ZIP приложения на macOS
npm run build:mac
```

Результаты сборки появятся в `release/`.

## 🔎 Поддержка языков и ограничения

**JavaScript, TypeScript, JSX и TSX** разбираются через TypeScript AST. Для **Python, C/C++, Java, C#, Rust и Go** используется упрощённое выделение символов, поэтому часть конструкций может не попасть на карту.

- Полный граф вызовов и межфайловое наследование пока не поддерживаются.
- Некоторые алиасы и вычисляемые импорты не разрешаются.
- Анализ ограничен 6 000 файлами.
- `node_modules`, `.git`, результаты сборки и другие служебные каталоги пропускаются.

## 🤝 Участие в разработке

Нашёл ошибку или придумал полезную функцию? [Создай Issue](https://github.com/whydoyouseegit/repomap/issues). Для ошибки укажи версию приложения, ОС и шаги воспроизведения. Если проблема связана с анализом кода, приложи небольшой пример без личных данных.

Чтобы предложить изменение:

1. Сделай форк репозитория.
2. Создай ветку: `git checkout -b feature/your-feature`.
3. Внеси изменения и проверь приложение через `npm start`.
4. Если меняешь анализатор, запусти `npm test` и добавь проверку нового поведения.
5. Сохрани изменения, отправь ветку в свой форк и открой Pull Request.
