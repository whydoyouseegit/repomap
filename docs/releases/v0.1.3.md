# Repo Map 0.1.3

Локальная программа, которая превращает проект в трёхмерную карту файлов, классов, функций и импортов.

## Скачать и установить

**Для Windows 10/11 x64 скачайте `Repo-Map-Setup-0.1.3-x64.exe`.** Запустите файл, выберите язык и папку установки. После установки откройте Repo Map и нажмите **Открыть папку**.

Это один автономный установщик. Node.js и npm не нужны. Git нужен только для клонирования по ссылке.

## Файлы выпуска

- **Repo-Map-Setup-0.1.3-x64.exe** — установщик Windows.
- **Repo-Map-Source-0.1.3.zip** — исходники с документацией и примером проекта.
- **Repo-Map-Release-Pack-0.1.3.zip** — установщик, исходники, короткая инструкция и контрольные суммы в одном архиве.
- **SHA256SUMS.txt** — SHA-256 для файлов выпуска.

## Что есть в программе

Открытие папки и Git-ссылки, вращение и приближение карты, поиск, просмотр кода и зависимостей, фильтры, режим кластеров и экспорт JSON без исходного кода.

JS/TS разбираются через AST; поддержка других языков пока упрощённая. Локальный анализ работает без интернета.

[Руководство пользователя](https://github.com/whydoyouseegit/repomap/blob/main/docs/USER_GUIDE.md).

У выпуска нет цифровой подписи. Windows SmartScreen может предупреждать о неизвестном издателе. Установщик не отключает средства защиты Windows.
