04 / Есть вопросы?

Перед запуском.

Больше деталей — в руководстве.
Идеи и ошибки — в GitHub Issues.

Какие языки поддерживаются?

JavaScript, TypeScript, JSX и TSX разбираются через TypeScript AST. Для Python, C/C++, Java, C#, Rust и Go пока используется упрощённое выделение классов и функций.

Код куда-нибудь отправляется?

Анализ выполняется локально в приложении. Для работы с папкой сеть не нужна. При подключении Git-репозитория программа скачивает его на компьютер через Git.

Можно пользоваться на macOS и Linux?

Готовый установщик выпускается для Windows 10/11 x64. Для Linux и macOS в репозитории есть команды сборки. Подробности — в документации для разработчиков.

Почему Windows показывает предупреждение?

Установщик пока не подписан цифровым сертификатом издателя. Поэтому SmartScreen может предупреждать о неизвестном приложении. Исходный код доступен для проверки и самостоятельной сборки.

Какие ограничения у альфа-версии?

Лимит — 6 000 файлов; служебные папки вроде node_modules и .git пропускаются. Карта показывает структуру и импорты, полного графа вызовов пока нет. После изменения файлов нужно нажать «Обновить».

Что показывает демо на этом сайте?

Это иллюстрация интерфейса на вымышленном проекте orbital-engine. Можно вращать вселенную, переключить кластеры и выбрать файл в примере. Для анализа своих проектов скачай локальное приложение.
