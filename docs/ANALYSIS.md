# Как анализируется код


**JavaScript / TypeScript / JSX / TSX:** используется AST TypeScript 5.9.3. Выделяются именованные классы, интерфейсы, функции, методы и стрелочные функции в переменных и полях класса. Разбираются `import`, `export ... from`, `require('literal')`, `import('literal')`; разрешаются локальные пути, файлы `index`, подстановка `.js → .ts` и `baseUrl`/`paths` из корневого `tsconfig.json`.

Это карта структуры и импортов, **не полный граф вызовов**. Вычисляемые импорты, анонимные callback-функции, межфайловое наследование и нестандартные алиасы сборщиков не разрешаются. `extends` конфигурации TypeScript пока не раскрывается. Неразрешённые и внешние импорты перечисляются отдельно.

**Python, C/C++, Java, C#, Rust, Go:** предварительное структурное выделение символов по текстовым правилам. Оно может пропустить сложные объявления или дать ложные совпадения; в инспекторе есть пометка «приблизительно». Для C/C++ также разрешаются локальные `#include "file.h"`. Остальные файлы показываются как файлы без разбора символов.

## Ограничения первой версии

- До 6 000 файлов. Если лимит достигнут, программа сообщает, что отображена часть проекта.
- Разбор содержимого: до 768 КиБ на файл и 32 МиБ текста на проект. Предпросмотр: до 80 000 символов файла и до 120 строк за один просмотр.
- Зависимости, результаты сборки и служебные папки (`.git`, `node_modules`, `dist`, `build`, `target`, `vendor`, `.venv` и др.) пропускаются. Символические ссылки не обходятся. `.env*` и распространённые файлы ключей исключены. Правила `.gitignore` пока не читаются.
- Файлы проекта не изменяются и не исполняются. Автоматического обновления карты при изменениях пока нет: используйте **Обновить**.
- Приватные репозитории требуют уже настроенного Git Credential Manager или SSH-ключа и известного ключа сервера. Токены в Git-ссылках не поддерживаются, интерактивный запрос Git отключён.
- Кэш клонов и список последних папок хранятся в пользовательском каталоге приложения. Обычно это `%APPDATA%/repo-map` на Windows. Управления очисткой кэша в интерфейсе пока нет.
