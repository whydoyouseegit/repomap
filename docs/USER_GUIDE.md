# Как пользоваться Repo Map

## 1. Установи программу

На [странице релизов](https://github.com/whydoyouseegit/repomap/releases/latest) скачай файл `Repo-Map-Setup-0.1.3-x64.exe`. Это обычный установщик: запусти его, выбери язык, нажми «Далее» и укажи папку, если стандартная не подходит. После установки появятся ярлыки Repo Map.

Никакие дополнительные библиотеки или Node.js устанавливать не нужно. Для работы с локальной папкой не нужен и Git.

Если вместо установщика ты скачал `Release-Pack`, распакуй его и запусти `.exe` внутри. Архив `Source` предназначен для разработки: готовой программы в нём нет.

## 2. Попробуй демо

При первом запуске ты увидишь проект `orbital-engine` с меткой **DEMO**. Это встроенный пример, а не файлы с твоего компьютера.

Покрути карту мышью, приблизь её колесом и нажми на любую точку. Справа откроется информация об узле. Можно также выбирать элементы в дереве слева.

## 3. Открой свой проект

Нажми **Открыть папку** в правом верхнем углу и выбери корневую папку проекта. Обычно это папка, в которой лежат `package.json`, `CMakeLists.txt`, `pyproject.toml` или основные исходники.

Подожди завершения анализа. Если проект большой, программа покажет прогресс; операцию можно отменить. После загрузки метка **DEMO** исчезнет, а в шапке появится имя твоей папки.

Выбирай папку одного проекта. Если открыть весь диск или домашнюю папку, в карту попадёт много лишних файлов и быстрее сработает ограничение по размеру.

## 4. Или открой Git-репозиторий

Для этого понадобится установленный [Git](https://git-scm.com/downloads). После установки Git перезапусти Repo Map.

1. Нажми **Git-ссылка**.
2. Вставь ссылку, например `https://github.com/whydoyouseegit/repomap.git`.
3. Нажми **Клонировать и открыть**.

Интернет нужен для клонирования. Полученная копия хранится на компьютере; код не отправляется на сервер анализа. Загружается текущая ветка без полной истории Git.

Приватные репозитории откроются, если доступ уже настроен через Git Credential Manager или SSH. Токены в URL и запрос пароля внутри программы не поддерживаются.

## 5. Разберись в карте

Крупные точки — файлы, ромбы — классы и интерфейсы, маленькие точки — функции и методы, квадраты — папки. Пыль вокруг узлов показывает относительный объём кода; это не отдельные файлы.

Нажми на узел. Справа появятся его путь, состав и найденные связи. Сплошные линии показывают импорты, пунктирные — принадлежность элемента файлу или классу. Нажимай на элементы в инспекторе, чтобы переходить между ними.

- **Вселенная** собирает проект в сферу.
- **Кластеры** разделяют его на скопления по папкам.
- **Все импорты** показывает связи одновременно. На большом проекте их может быть слишком много; тогда удобнее выбирать отдельные узлы.
- Фильтры справа позволяют оставить только файлы, классы или функции.

## 6. Найди нужный файл или класс

Нажми `/` или поле поиска слева. Введи часть имени: например `Engine`, `main` или `utils`. Выбери результат в дереве, чтобы перейти к нему на карте.

В инспекторе есть вкладка **Код**. Она показывает текстовый фрагмент с номерами строк. Кнопка **Показать в проводнике** открывает расположение исходного файла.

## 7. Обнови или сохрани карту

Если ты изменил исходники в редакторе, нажми **Обновить**. В этой версии автоматического слежения за изменениями нет.

Кнопка **JSON** сохраняет структуру и связи в отдельный файл. Исходный код в экспорт не включается. Список **Недавние** помогает снова открыть ранее выбранные папки.

## Управление

| Действие | Кнопка |
| --- | --- |
| Вращение | Левая кнопка мыши + движение |
| Сдвиг | Правая кнопка мыши или Shift + левая |
| Масштаб | Колесо, `+`, `−` |
| Выбор узла | Один клик |
| Фокус на узле | Двойной клик или выбор в дереве |
| Поиск | `/` |
| Пауза / продолжение вращения | Пробел |
| Исходный ракурс | `R` |
| Снять выделение | `Esc` |

## Если что-то не получается

**На карте не все классы или связи.** Для JS/TS используется синтаксический разбор. Остальные поддерживаемые языки пока разбираются приблизительно. Вычисляемые импорты, некоторые алиасы и межфайловое наследование не разрешаются. [Ограничения анализа](ANALYSIS.md).

**После изменения кода карта осталась прежней.** Нажми **Обновить**.

**Git не найден.** Установи Git, закрой Repo Map и запусти снова. Для локальной папки Git не нужен.

**Windows пишет «Неизвестный издатель».** У текущей версии нет цифровой подписи. Мастер установки не отключает SmartScreen или антивирус. [О подписи и проверке файлов](WINDOWS_SIGNING.md).

**Старая иконка после обновления.** Закрой старую программу, установи актуальную версию и открой новый ярлык. Версию можно посмотреть в шапке программы и в свойствах файла.

**Как удалить программу?** Открой настройки Windows → Приложения → Установленные приложения → Repo Map → Удалить. Исходники твоих проектов не затрагиваются. Настройки и кэш клонов сохраняются в `%APPDATA%/repo-map`; при необходимости их можно удалить отдельно после закрытия программы.
