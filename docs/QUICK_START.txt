REPO MAP 0.1.3
Создатель: /home/whydoyousee
GitHub: https://github.com/whydoyouseegit/repomap

УСТАНОВКА
1. Запусти Repo-Map-Setup-0.1.3-x64.exe.
2. Выбери язык и папку установки.
3. Открой Repo Map через созданный ярлык.
4. Нажми «Открыть папку» и выбери свой проект.

Node.js и npm не нужны. Git нужен только для открытия Git-ссылок.
Локальная папка анализируется без интернета.

УПРАВЛЕНИЕ
Левая кнопка мыши — вращение. Правая — сдвиг.
Колесо — масштаб. Пробел — пауза. R — исходный ракурс.
Нажми на узел, чтобы увидеть связи и код.
После изменения исходников нажми «Обновить».

ИСХОДНИКИ
Repo-Map-Source-0.1.3.zip содержит код, документацию и пример проекта.
Руководство: docs/USER_GUIDE.md в архиве исходников или на GitHub.

Версия не имеет цифровой подписи: Windows может показать предупреждение.
Контрольные суммы в CONTENTS-SHA256.txt относятся к файлам этого пакета.
